# Como rodar

**Linux:**
```bash
python ou py -m venv venv
source venv/bin/activate (ativa o servidor)
pip install -r requirements.txt
python ou py app.py
```

**Windows:**
```bash
 python ou py -m venv venv
.\venv\Scripts\activate -- se nao funcionar, mude para Git bash e rode --> source venv/Scripts/activate
pip install -r requirements.txt
python ou py app.py
```
